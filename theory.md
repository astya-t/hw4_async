# Теоретическая часть

1. **Парсер, считающий хеши 10 000 файлов — процессы.**
   Основная работа — вычисление хешей (CPU-bound), а процессы дают настоящий
   параллелизм на всех ядрах без ограничения GIL.

2. **Бот, обращающийся к 5 внешним API на каждый запрос — async.**
   Это чистое ожидание сети (I/O-bound): 5 запросов запускаются через gather
   и ждутся одновременно, а тысячи пользователей обслуживаются в одном потоке дёшево.

3. **Скрипт, выгружающий 100 000 строк из БД пачками — async (или потоки).**
   Время уходит на ожидание ответов БД (I/O-bound): с асинхронным драйвером
   (asyncpg) — async, с синхронным драйвером — потоки; процессы не нужны,
   считать почти нечего.
